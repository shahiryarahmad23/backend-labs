# backend-labs
Fundamentals practice for backend engineering — Python internals, raw SQL, AI tooling, Git, and DSA.

## why this repo exist 
I am building a mobile application backend for a client project.That repo is private and practice drills can't live there. Drill,experiments and AI-tooling trails stay here and only the understood work cross into the project.

## Method
A drill isn't finished when it works — it's finished when I've broken it on purpose and read the error. 

ai/README record what AI-tool got right and what is got wrong and what i changed in the result.

## Structure
|Directory|Contains|
|python/README|Python concepts , exercises and experiments with focus of backend development
|sql/README|Raw SQL queries, exercises and how sql work with any ORM
|ai/README|AI-tooling experiments, trials and how it can be used effectively in development workflow
|dsa/README|DSA problems for building problem solving skills and understanding different solution efficiency
|git/README|Git and Github concepts and how they work in real-world software development
